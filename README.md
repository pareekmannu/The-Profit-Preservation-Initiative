# The Profit Preservation Initiative

End-to-end retail analytics project focused on identifying profit leakage caused by returns, regional performance gaps, and risky customer behavior.

## Business Objective

Despite sales growth, net profitability remained flat. This project investigates the drivers of profit erosion and produces actionable recommendations for operations and customer strategy.

## Tech Stack

- Python 3.x
- Jupyter Notebook
- Pandas, NumPy
- Matplotlib, Seaborn

## Repository Structure

- `notebooks/` - analysis notebooks
- `outputs/tables/` - generated output tables for reporting and dashboards
- `data/raw/` - optional location for original raw data files

## Main Analysis Areas

1. Data preparation and metric engineering
2. High-return product identification
3. Regional performance audit
4. Customer segmentation (loyalists vs. serial returners)

- `notebooks/project_data_checkpoint.ipynb`
